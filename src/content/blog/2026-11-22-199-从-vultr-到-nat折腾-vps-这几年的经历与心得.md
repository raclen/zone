最早接触 VPS，是因为看到了别人搭建节点的教程。当时对 VPS 还不太了解，只是想着自己搭建一个节点，方便日常使用。

这几年陆陆续续折腾过不少 VPS，从最开始的 Vultr，到便宜的 NAT 小鸡，再到 Oracle、AWS 和 Google Cloud，也算踩过不少坑。

现在回头看，其实对于我这种使用需求不高的人来说，根本没必要花太多钱买 VPS。一台便宜的 NAT 小鸡，基本就能满足日常需求。

这篇文章记录一下这些年的折腾经历，以及目前手上还在使用的几台机器。

## 一、最早接触 VPS：Vultr

第一次接触 VPS，是看别人搭建节点的教程。

当时选择的是 Vultr，充值 10 美元送 10 美元，相当于花 10 美元获得了 20 美元的余额，折合人民币大概 140 元。

刚开始觉得挺划算，买了一台机器，按照教程搭建了自己的节点。

不过，VPS 毕竟是按小时计费的，当时对计费规则也不太了解。结果用了大概 4 个月，赠送的额度用完，后来还产生了欠费。

这次经历之后，很长一段时间都没有再自己搭建节点。

## 二、重新折腾 VPS：便宜的 NAT 小鸡

后来因为购买域名，接触到了 NodeLoc 这个社区。

在社区里又开始关注 VPS，发现原来还有很多价格非常便宜的机器。

当时在 UlziX 买了美国和英国的 NAT 机器，价格非常便宜，5～7 元一年。

看到这个价格，忍不住买了几台尝试。

不过，便宜确实有便宜的代价，机器用了大概一周就无法正常使用了。

虽然体验不太好，但也让我开始了解 NAT VPS，以及低成本搭建节点的玩法。

## 三、接触 AI：开始折腾 Oracle Cloud

后来，我已经不满足于单纯搭建 sing-box 节点了。

随着 AI 工具越来越多，平时需要使用各种 API，于是开始折腾 CPA，以及各种 API 反代服务。

这时候就申请了 Oracle Cloud 的免费机器。

当时申请 Oracle 使用的是手机网络，没有开 VPN，绑定 Visa 卡，一次就成功开通了。

申请成功之后，搭建了不少 API 反代服务，例如 CPA 等。

<img width="995" height="563" alt="image" src="https://github.com/user-attachments/assets/54b01410-238c-4946-9f06-bae833a6861c" />

实际上，这类服务对服务器的性能要求并不高，1H1G 的机器基本就够用了。

可惜的是，这台 Oracle 机器用了大概 3 个月就被封了。

对于免费云服务器来说，账号风控始终是一个需要考虑的问题。即使申请成功，也不代表能够长期稳定使用。

如果想了解 Oracle Cloud 的申请过程，可以参考这个视频：

[Oracle Cloud 免费服务器申请教程](https://www.youtube.com/watch?v=4SBD3Gu8tus)

## 四、目前手上的 VPS

经过这几年的折腾，现在对 VPS 的需求反而越来越简单了。

平时主要就是搭建一个 sing-box 节点，以及 CPA、API 反代之类的服务。

对于我的使用场景，一台 256MB 内存的 NAT 小鸡其实就能满足基本需求，完全没必要专门花钱买一台配置很高的 VPS。

目前手上主要有以下几台机器。

### 1. 无聊云：洛杉矶 NAT

官网：[无聊云](https://56idc.net/)

目前使用的是洛杉矶 NAT VPS，配置如下：

| 配置 | 参数 |
| --- | --- |
| 机房 | 洛杉矶 |
| CPU | 1 核 |
| 内存 | 512MB |
| 流量 | 1TB |
| IP | IPv4 + IPv6 |
| 价格 | 10 元/年 |

这个价格可以说非常便宜了，一年只需要 10 元。

目前这台机器主要部署了 sing-box 和 agent2api。

平时测试下来，Gemini 和 ChatGPT 都可以正常使用，基本满足我的日常需求。

目前内存占用情况：

`106.04 MB / 512 MB`

512MB 内存还有不少剩余，对于我目前的用途来说完全够用。

### 2. 独角鲸云：主要用于搭建节点

官网：[独角鲸云](https://dash.fuckip.me/)

这台机器主要用来搭建节点。

它支持月付，价格比较便宜，不需要一次性投入太多成本。

对于流量需求，我个人其实并不高。每个月 200GB 左右就够用了，平时也没有大量下载或者视频流媒体需求。

### 3. AWS Lightsail：2H1G

AWS Lightsail 这台机器是通过新用户赠金开通的。

目前使用的是 2H1G 配置，按照当时的活动和赠金情况，计划免费使用半年。

申请时使用了 QQ 邮箱和手机网络，没有绑定银行卡也成功开通了。

目前主要在这台机器上部署 CPA。

不过，经历过 Oracle 被封的事情之后，我对免费云服务器的稳定性和账号安全更加谨慎了。

所以这台机器暂时不准备部署节点，主要用于其他服务。

### 4. Google Cloud：2H1G 免费实例

Google Cloud 也是之前折腾免费云服务器时关注的一个平台。

按照 Google Cloud 的免费套餐规则，在符合条件的情况下，可以长期免费使用一台 E2-micro 实例。

免费资源主要包括：

- 每月 1 台非抢占式 E2-micro 虚拟机。
- 指定美国区域：俄勒冈（us-west1）、爱荷华（us-central1）、南卡罗来纳（us-east1）。
- 每月 30GB 标准永久性磁盘。
- 每月 200GB 网络出站流量（符合免费套餐条件的区域和流量规则）。
- 入站流量通常不收费。

需要注意，免费套餐有区域、机器类型和流量等限制，超出免费额度的部分可能产生费用，不能简单理解为所有 2H1G 实例都永久免费。

申请教程可以参考：

[Google Cloud 免费服务器申请教程](https://www.youtube.com/watch?v=mLp1421t88Q)

目前这台机器主要作为备用，不打算用来搭建节点。

## 五、为什么现在不愿意折腾免费云服务器了？

之前 Oracle 被封的经历，让我对免费云服务器有了新的认识。

虽然 Oracle、AWS、Google Cloud 都有免费资源或者新用户赠金，但它们毕竟是商业云服务平台。

申请账号、使用资源，都需要遵守平台的规则。尤其是涉及 API 中转、代理服务等用途时，更应该提前了解平台的使用政策，避免违规使用。

目前我的想法是：

- AWS：主要部署 CPA 等服务。
- Google Cloud：保留备用，遵守免费套餐和平台规则。
- 独角鲸云：主要用于搭建节点。
- 无聊云：部署 sing-box 和 agent2api。
- Cloudflare：作为备用节点方案。

既然独角鲸云和无聊云的流量已经完全够用，就没有必要再把 AWS 和 Google Cloud 用来部署节点了。

免费云服务器能用固然很好，但没必要为了省一点钱，把账号和其他服务也搭进去。

## 六、最后总结

这几年折腾 VPS，最大的感受就是：配置并不是越高越好，适合自己的需求才最重要。

最开始为了搭建一个节点，花钱买 Vultr；后来为了省钱，尝试各种几块钱一年的 NAT 小鸡；再后来接触 AI，又开始折腾 Oracle、AWS、Google Cloud。

现在反而回到了最简单的状态。

对于我这种平时使用不多的人来说：

- 256MB～512MB 内存，基本够用。
- 每月 200GB 流量，基本够用。
- 一年花十几块钱，就能解决大部分需求。

与其花几十甚至上百元买一台高配置 VPS，长期闲置，不如根据自己的实际需求选择合适的机器。

当然，便宜 VPS 也有缺点，比如线路、稳定性、售后和商家经营风险，都需要自己承担。

折腾 VPS 这么久，现在最大的心得就是：**够用就好，没必要为了折腾而折腾。**
